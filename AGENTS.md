# AGENTS.md

## Project Context
This is the *MONEDA GUARANI (\$GCOIN)* DePIN ecosystem repository. It contains the decentralized application (DApp) dashboard designed for global internet bandwidth monetization analytics and node infrastructure operations connected to the Solana blockchain.

## Tech Stack & Runtime Environment
- *Runtime & Tooling:* Bun (v1.4.2+) - Do NOT use npm, pnpm, or yarn.
- *Frontend Framework:* React + Vite
- *Language:* TypeScript (Strict mode enabled)
- *Styling:* Tailwind CSS

## Critical Setup & Agent Commands
All commands must be executed using the bun binary runtime:

- *Install dependencies:* bun install
- *Start development server:* bun run dev
- *Build production asset bundle:* bun build ./index.html --production
- *Execute test suite:* bun test

## Code Style & Development Guidelines
- Maintain strict type safety across all Solana network operations and node metric parsing.
- Use functional programming patterns and native ESM components for the bandwidth dashboard.
- Ensure all automated route analytics and CandleChart metrics fetch data securely over active SSL hooks.
- Never clear or bypass the dependency cache lockfile unless explicit structural changes are requested.
